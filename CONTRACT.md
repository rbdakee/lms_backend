# Контракт API

Фронт работает от примеров из этого файла и не гадает. Форма ответа меняется
только вместе с этим файлом.

## Общие правила

- Всё, что пересекает границу, — через `_`: поля JSON и пути
  (`/quiz_attempts`, не `/quiz-attempts`).
- Время — ISO 8601 в UTC: `"2026-08-16T09:30:00Z"` (может прийти и как
  `+00:00`). Показ по казахстанскому времени — забота фронта.
- Сессия — кука `sid`: HttpOnly, `SameSite=Lax`, в бою на домене `.domain.kz`.
  Фронт токен не видит и не хранит, запросы шлёт с `credentials: "include"`.
- Успешный ответ без тела — `204 No Content`.

## Формат ошибки — один на все эндпоинты

```json
{
  "error": {
    "code": "wrong_code",
    "message": "Неверный код",
    "details": { "attempts_left": 2 }
  }
}
```

- `code` — машинное имя для ветвления на фронте, `message` — готовый текст
  по-русски, `details` — данные для экрана; поля нет, если показывать нечего.
- Ошибка валидации (422) всегда несёт список полей:

```json
{
  "error": {
    "code": "validation_error",
    "message": "Проверьте заполнение полей",
    "details": {
      "fields": [
        { "field": "phone", "message": "Field required" }
      ]
    }
  }
}
```

- Лимиты (429) всегда несут `details.retry_after_sec`.
- Коды, общие для всех эндпоинтов: `unauthorized` (401 — нет или умерла
  сессия), `blocked` (403 — учитель заблокирован), `forbidden` (403),
  `not_found` (404), `validation_error` (422), `rate_limited` (429),
  `internal_error` (500).

## Постраничные списки

Запрос: `?page=1&per_page=20` (per_page ≤ 100). Ответ:

```json
{ "items": [], "total": 0, "page": 1, "per_page": 20 }
```

Пустая страница — это `items: []` с настоящим `total`, а не ошибка.
