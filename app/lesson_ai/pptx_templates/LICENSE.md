# Лицензии библиотеки шаблонов

## Оформление

Геометрия, палитра и тексты-заполнители шаблонов (`library.pptx`, `catalog.toml`,
`previews/`) сделаны для «Жоспара» с нуля, стоковых фото и чужих макетов нет.

## Шрифты

В `.pptx` шрифты **не встраиваются** — файл только называет семейство, рисует
шрифт того компьютера, где презентацию открыли.

| Где | Семейство | Запасное | Откуда у учителя |
|---|---|---|---|
| заголовки, крупные числа | Verdana | Tahoma → Arial | входит в Windows и macOS |
| текст слотов | Arial | Helvetica | входит в Windows и macOS |

Оба семейства — системные шрифты Microsoft (Verdana — Matthew Carter, Arial —
Monotype), распространяются вместе с ОС; мы их не распространяем и не встраиваем.
Казахские буквы (ә ғ қ ң ө ұ ү һ і и прописные) в обоих есть — проверено по таблице
символов файлов Verdana/Arial из macOS и на снимке `previews/title__filled_kz.png`
(«Әдебиеттік оқу … Қазақ тілі»). Trebuchet MS и Arial Rounded отвергнуты: в них
нет казахских букв.

## Картинки

Значки `deco:true_mark` / `deco:false_mark` (слайд `true_false`) — файлы `check.png`
и `cross.png` каталога `app/lesson_ai/images/`: Fluent Emoji (Microsoft, MIT),
условия — `app/lesson_ai/images/LICENSE.md`. Картинки на снимках `__filled`
оттуда же. Других картинок в библиотеке нет: места под картинки — пустые рамки
`slot:*`, их заполняет исполнитель из того же каталога.

## Сборка

Снимки сняты headless Chromium (Playwright, Apache-2.0) во временной папке;
в зависимости проекта ни он, ни Node не входят — см. `build/README.md`.
